Pick up where your project stopped.

DORMBIT finds the projects you stopped touching, seals each one into a capsule you can verify, and restores it byte for byte. Then it tells you where you left off.

    One file you can carry.

  4. Step 4 of 6 · Verify

    Re-hash everything.

    Each object is hashed again with SHA-256 and compared with the manifest. A damaged capsule fails loudly and names the file.

    Into a new folder, all at once.

    Files are staged and verified first, then moved into place in one step. An interrupted restore never leaves a half-written project.

Hard limits, printed on the box.

These aren't settings. They're enforced in the build: banned APIs, an allowlist of 28 commands, and tests that fail if either one changes.

Operating limits

Never deletes your files
It reads and copies. Cleanup touches only its own staging folder.
Never runs your code
No shell, no build, no git command line. Git is read through libgit2.
Never uploads anything
No account, no telemetry, no network calls. Capsules stay on your disk.
Asks before reading agent sessions
Claude Code, Codex, and Kiro exports are read for metadata only, after you switch each one on.
Restores into a new folder
It refuses to write into a folder that already exists.
