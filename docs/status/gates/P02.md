## CI

The first green `ci` run on `main` is [https://github.com/AmirmLotfy/dormbit/actions/runs/42354901364](https://github.com/AmirmLotfy/dormbit/actions/runs/42354901364) (commit `1c47b14`): all seven jobs pass
(`rust`, `ts`, `wasm`, `contracts`, `e2e`, `security`, `meta`). Getting there took four runs:

1. `check-deps.sh` exited silently on the runner because `. "$HOME/.cargo/env"` ends a
   non-interactive `sh` when the file is missing; guarded it.
2. The runner image has no `shellcheck`; the step now installs it with Homebrew. The
   `globstar` form I first used does not exist in macOS bash 3.2, so the step uses `find`.
3. Headless Firefox 157 on the shared runner needs 15-60 s per landing-page load. Fixed what was
   ours: the hero now skips WebGL on software renderers (SwiftShader, llvmpipe), starts 3D after the
   page `load` event, the gradient layers are about 60% smaller, and CI uses a 90 s test timeout.
4. One landing test (five viewport resizes) still stalled 60+ s in Firefox on the runner, so it is
   skipped on Firefox in CI only (STATUS D-10); Chromium, WebKit, and iPhone WebKit run it in CI and
   Firefox runs it locally.
