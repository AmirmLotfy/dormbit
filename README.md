# DORMBIT

**Pick up where your project stopped.**

A local-first, privacy-focused project preservation and recovery utility for macOS developers. DORMBIT helps you understand a dormant software project, preserve its approved state in an independently verified capsule, safely restore it, and generate an accurate handoff ("Resurrection Brief") for continuing the work.

DORMBIT does five things: **discover → understand → preserve → verify → revive.** It is not a disk cleaner and it never deletes your projects.
